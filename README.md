# Ondas a un click
## Autor: Jhasper Rojas

**Descripcion objetiva :**
Un sistema visual en p5.js que muestra una grilla de formas geométricas. Al mover el mouse, las figuras cambian tamaño y forma; al hacer click, se generan ondas expansivas que alteran color y vibración de forma random.

-**Inputs :**
posición del mouse, clicks.
-**Outputs :**
variación de color, forma y tamaño en tiempo real.

**Descripción conceptual :**
El proyecto dialoga con el Op Art y el arte cinético, explorando la percepción visual mediante reglas computacionales. La lógica de ondas y variaciones traduce la idea de movimiento y vibración óptica a un sistema generativo.

**Input / Output y sistema**
- **Inputs:** posición del mouse y clicks.  
- **Procesos:**  
  - (map) para transformar distancia en tamaño.  
  - (random) para generar vibraciones y colores aleatorios.  
  - Condicionales para decidir forma y color según cercanía del mouse.  
- **Decisiones:**  
  - Si el mouse está cerca → cuadrados azules.  
  - Si está lejos → triángulos de color variable.  
  - Si hay ondas activas → vibración y cambio de color.  
- **Outputs:** figuras que cambian en tiempo real, ondas expansivas que modifican la grilla.
